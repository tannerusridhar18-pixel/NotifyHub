# NotifyHub Auth UI

Frontend-only NotifyHub interface with a landing page plus five authentication pages:

- Landing page
- Authentication entry page
- Admin login
- Faculty login
- Faculty registration
- Student login
- Student registration

## Run

```bash
npm start
```

Then open:

- `http://localhost:3000` for the landing page
- `http://localhost:3000/auth.html` for the authentication entry page

## Notes

- Static HTML, CSS, and JavaScript only
- No backend, API, database, or real authentication
- Simulated validation, loading, and success states

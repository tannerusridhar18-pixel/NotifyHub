# NotifyHub Frontend

A production-oriented Next.js frontend for the NotifyHub Smart Campus Announcement Platform.

## Stack

- Next.js 16.3
- React 19.2
- TypeScript
- Tailwind CSS v4
- Spring Boot REST API
- MySQL backend

## Authentication

NotifyHub uses HttpOnly cookie-based sessions. The frontend does not store access or refresh tokens in localStorage. The backend remains authoritative for authentication, authorization, validation, and persistence.

The admin portal is separate from the student/faculty portal. Role routing uses the role information returned by the backend login/current-user APIs.

## Backend contract

The browser uses the relative API base `/api/v1` by default. Next.js rewrites that path to `NOTIFYHUB_BACKEND_ORIGIN`, which avoids browser-side localhost/127.0.0.1 CORS mismatches.

Key endpoint groups include:

- Authentication: `/auth/login`, `/auth/register`, `/auth/refresh`, `/auth/logout`, `/auth/forgot-password`, `/auth/reset-password`
- Identity: `/users/me`
- Announcements: public feed, urgent feed, management, create/update/publish/archive/unpublish/delete
- Events: public feed, upcoming, management, create/update/publish/cancel/unpublish/delete
- Queries: public submission, student/faculty inboxes, scoped/admin listing, answers
- Invitations: admin invitation creation and invitation listing
- Academic/hostel structure management
- Role and user management

## Run locally

1. Copy `.env.example` to `.env.local`.
2. Keep `NEXT_PUBLIC_API_URL=/api/v1` for the standard local setup.
3. Set `NOTIFYHUB_BACKEND_ORIGIN` to the backend origin if it is not `http://localhost:8080`.
4. Install dependencies:

```bash
npm ci
```

5. Verify the frontend:

```bash
npm run lint
npm test
npm run build
```

6. Start development:

```bash
npm run dev
```

Open `http://localhost:3000`.

## Production configuration

Set:

- `NEXT_PUBLIC_API_URL=/api/v1` when using the Next.js rewrite.
- `NOTIFYHUB_BACKEND_ORIGIN` to the reachable Spring Boot backend origin.

Do not commit `.env.local` or real credentials.

## Source hygiene

The source package intentionally excludes generated artifacts and local caches, including `node_modules`, `.next`, `coverage`, logs, IDE files, and `*.tsbuildinfo`. `package-lock.json` is retained for reproducible dependency installation.
`next-env.d.ts` is generated by Next.js and is ignored for future commits; an already-tracked copy may remain in Git history without affecting the build.
